Set up your agent

Your ZestQA agent runs on YOUR own infrastructure. We'll walk you through it — takes about 5 minutes.

1
Create a free HuggingFace account

HuggingFace is where your agent will live and run. It's free and takes 30 seconds to set up.

Create account at huggingface.co →
Already have one? Skip to step 2 ↓
2
Create a new Space

A Space is where your agent code runs. Think of it like a mini server just for your agent.

  1. Go to huggingface.co/new-space
  2. Choose Docker as the Space SDK
  3. Name it anything you like (e.g. "my-qa-agent")
  4. Set visibility to Public
  5. Click Create Space
Open HuggingFace →
3
Add 4 secrets to your Space

In your Space → Settings → Variables and secrets, add these 4 values. We'll help you generate them.

SESSION_SECRET
Signs your dashboard login sessions securely
SQA_USERS
Your dashboard login credentials (email + hashed password)
GROQ_API_KEY
Free AI model access for test generation and chat
Get free key →
STAGING_URL + PRODUCTION_URL
Your product's portal URLs
4
Push your agent code to the Space

This sends the ZestQA agent code to your Space. Run this command in your terminal:

git remote add space https://huggingface.co/spaces/YOUR-USERNAME/YOUR-SPACE-NAME git push space main

Once your Space is running (takes 2-3 minutes after push), enter your Space URL below:

Your HuggingFace Space URL
