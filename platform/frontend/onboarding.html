Connect your HuggingFace Space

Your agent runs on YOUR HuggingFace Space — your data never touches our servers.

ZestQA only stores your theme, project name, and which integrations you've turned on. Credentials, test data, and everything your agent does at runtime stay on the Space you control.
Create a free account at huggingface.co if you don't have one already.
Click New Space → choose the Docker SDK → name it anything you like.
In your Space's Settings → Variables and secrets, add the secrets below.
SecretDescription
SESSION_SECRETRandom string used to sign dashboard login sessions
SQA_USERSJSON list of dashboard login accounts (email + bcrypt password hash)
STAGING_URL / PRODUCTION_URL / LOCAL_URLYour product's portal URLs per environment
STAGING_API_URL / PRODUCTION_API_URLYour backend API URLs per environment
SELLER/ADMIN/AGENCY_STAGING_EMAIL / _PASSWORDStaging portal login credentials per role
SELLER/ADMIN/AGENCY_PRODUCTION_EMAIL / _PASSWORDProduction portal login credentials per role
JIRA_BASE_URL / JIRA_EMAIL / JIRA_API_TOKENJira integration for ticket automation
GROQ_API_KEYAI model access (test generation, chat assistant)
GITHUB_TOKENAzure GPT-4o fallback + repo access for branch tools
SLACK_WEBHOOK_URLPosts run reports to a Slack channel
PRODUCTION_DB_HOST / _PORT / _USER / _PASSWORD / _NAMEOptional read-only DB access for health checks
GITHUB_FRONTEND_REPO / GITHUB_BACKEND_REPORepo paths for branch management tools
SUPABASE_URL / SUPABASE_ANON_KEYLets your dashboard load your ZestQA theme and confirm your session
Push the agent code to your Space:
git remote add space https://huggingface.co/spaces/YOUR-USERNAME/YOUR-SPACE-NAME git push space main
